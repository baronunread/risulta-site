Run the server, dashboard, authentication, and collector from one Bun-compiled Linux binary.

Many websites

Manage multiple domains from one login while keeping every website’s analytics in its own SQLite database.

One command

From a fresh VPS
to a private dashboard.

The installer downloads the correct checksum-protected release, creates your administrator, registers a hardened system service, and can configure Caddy with automatic HTTPS.

  1. 1Point a domain at your Debian or Ubuntu server.
  2. 2Run the command as root and answer the prompts.
  3. 3Sign in and add the websites you want to measure.
