What ships in the binary

Collector and dashboard

Pageview ingestion, authentication, reports, and administration run in one process.

Multiple websites

One login manages many domains while each website keeps an independent SQLite database.

Cookie-free visitor counts

Daily server-side hashes count visitors without storing raw IP addresses or linking activity across days.

Auditable source

The server is AGPL-licensed. The 441-byte compressed browser tracker is MIT-licensed.

Install

One command on Debian or Ubuntu

The installer verifies the release checksum, creates the administrator and system service, and guides HTTPS setup. Running it again updates the binary without replacing your data or account.

  1. 1Point a domain to the server’s public IP.
  2. 2Run the command and answer the prompts.
  3. 3Sign in and add the websites you want to measure.
root@server
curl -fsSL https://baronunread.github.io/risulta-site/install.sh | sudo sh
