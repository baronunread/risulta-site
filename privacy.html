Privacy.

Effective August 24, 2026.

This website

The Risulta marketing website does not set cookies, create accounts, or run a visitor analytics tracker. The static files may be served by a hosting provider, which can process ordinary request information such as IP addresses and user-agent headers to deliver and secure the site.

External services

Links to GitHub and other third-party documentation take you to services governed by their own privacy policies. Running the installer downloads release files from GitHub and, when you request Caddy installation, packages from Caddy’s official repository.

Self-hosted Risulta

A Risulta installation belongs to its operator. Administrator email addresses, sessions, configured websites, and analytics events stay in the operator’s data directory unless the operator moves or backs them up elsewhere. Risulta includes no hidden telemetry or hosted control plane.

Visitor measurement

The browser tracker sets no cookies. The server combines request information with a salt that changes daily to calculate an anonymous visitor hash. Raw IP addresses are not stored, and the daily salt prevents the same browser from being recognized across days.

Your responsibilities

If you operate Risulta, you decide why analytics are collected, how long data is retained, who can access it, and which laws apply. Publish privacy information appropriate to your websites and jurisdiction.

Questions

Open a question in Risulta’s public issue tracker. Do not include private analytics data or credentials.
