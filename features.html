Features

What the binary does

Risulta covers pageview analytics, multi-site access, and basic server operations. It deliberately omits product analytics, advertising attribution, and a managed control plane.

Reports

Routine traffic questions are available without building custom reports.

Summary
Unique visitors, visits, pageviews, and views per visit for today, seven days, or thirty days.
Current visitors
Anonymous visitors active during the last five minutes.
Breakdowns
Top pages and referrers for the selected period.

Websites and access

One Risulta process can serve many domains without mixing their analytics.

Multiple websites
Administrators manage every configured domain through one login.
Viewer accounts
Viewers can be restricted to selected websites.
Per-site isolation
Each website has its own tracker key, domain check, dashboard, and SQLite file.

Why the tracker is 441 bytes compressed

The browser code records pageviews only. It leaves aggregation and anonymous visitor counting to the server.

Native browser APIs
It uses fetch, history events, location, and document.referrer without a client library.
No identity package
There are no cookies, local storage, fingerprinting routines, or browser-side sessions.
No bundled product suite
It does not ship replay, feature flags, advertising tags, form capture, geolocation, or a general event SDK.

Server operation

The released executable includes Bun, the HTTP server, dashboard, authentication, collector, and SQLite integration.

Runtime
No Bun, Node.js, package manager, or external database is installed on the server.
Storage
Control data uses one SQLite database; analytics use one SQLite database per website.
Deployment
The installer registers a systemd service, verifies checksums, and can configure Caddy for HTTPS.
