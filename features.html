Features

Small software.
Complete essentials.

Risulta answers the common traffic questions without turning your analytics server into an infrastructure project.

Understand the traffic that matters.

One dashboard shows unique visitors, visits, pageviews, views per visit, current visitors, top pages, and top referrers across useful time ranges.

01

Clear summaries

Today, seven-day, and thirty-day views keep routine questions one selection away.

02

Live signal

See how many anonymous visitors were active during the last five minutes.

03

Useful breakdowns

Find the pages people visit and the sources that sent them—without building a report.

One login for every website.

Run a single Risulta instance for multiple domains. Administrators can see everything; viewer accounts can be restricted to selected websites.

04

Per-site isolation

Each website gets its own tracker key, domain verification, dashboard, and SQLite database.

05

Practical access control

Use administrator and viewer roles with site-level assignments from the dashboard.

06

One process

The collector, authentication, dashboards, and every configured website run together.

Private by construction.

The tracker sets no cookies. Risulta derives daily anonymous visitor hashes and does not retain raw IP addresses, preventing recognition across days.

07

Tiny tracker

The current keyed tracker is 638 bytes raw and 441 bytes compressed.

08

No hidden telemetry

Your Risulta server does not report usage back to a hosted control plane.

09

Auditable source

The server is AGPL-licensed and the embeddable tracker is MIT-licensed.

Operations without a stack.

Download one executable, keep one data directory, and use familiar systemd and Caddy configuration on a small Linux server.

10

Single binary

No Bun installation, container runtime, application dependencies, or external database at runtime.

11

SQLite storage

Control data lives in one database; analytics are separated into one database per website.

12

Health and shutdown

A health endpoint and clean process termination make routine service management predictable.
