How Risulta differs

Risulta minimizes the software required for self-hosted pageview analytics. The tradeoff is a smaller feature set than mature analytics suites.

Risulta fits if

  • You want pageview analytics on one small VPS.
  • You operate multiple websites through one login.
  • SQLite and a narrow feature set are advantages.
  • You are responsible for backups, updates, and uptime.

Use another tool if

  • You need funnels, revenue, geolocation, replay, or campaign tooling now.
  • You want a managed service and support contract.
  • You need distributed ingestion or high availability.
  • You need advertising attribution or an integration catalog.

Why Risulta is smaller

The tracker sends one pageview payload containing the path, referrer, and hostname. It uses browser-native APIs for initial loads and SPA navigation. Cookies, session management, visitor hashing, aggregation, replay, automatic element capture, and product analytics are not shipped to the browser.
